Instalación NODO POS — Tablet Android 6

Guía para el técnico. Preparar el equipo antes de entregarlo al cliente.

Importante: esta página se abre en tu PC o celular, no en la tablet que estás preparando. Android 6 no reconoce los certificados TLS actuales (Let's Encrypt / GTS), así que su navegador de fábrica no puede abrir sitios HTTPS como este. Descargá los archivos acá y pasalos a la tablet por cable USB.
1

Instalar Chrome 88

Necesario porque el navegador de fábrica de Android 6 tampoco puede abrir la PWA del POS (mismo problema de certificados). Chrome 88 sí la reconoce.

⬇ Descargar Chrome 88 (APK) ~12 MB
  1. Copiá el .apk a la tablet (cable USB, carpeta Download).
  2. En la tablet, abrí el explorador de archivos y tocá el .apk.
  3. Si pide permiso, activá "Instalar apps de fuentes desconocidas" para esa app y confirmá.
  4. Abrí Chrome una vez para completar la configuración inicial.
2

Instalar BT Print Server

Corre en segundo plano y conecta la impresora Bluetooth o de red con el POS (servidor local en 127.0.0.1:8080).

⬇ Descargar BT Print Server (APK)
  1. Mismo procedimiento: pasar por USB e instalar desde el explorador de archivos.
  2. Anotá la MAC de la impresora Bluetooth (o la IP si es de red) — se piden al conectar dentro del POS.
3

Abrir NODO POS

Con Chrome 88 ya instalado, abrí la URL del sistema y agregala a la pantalla de inicio para que funcione como app.

  1. Abrí Chrome → entrá a la URL del POS del cliente.
  2. Menú (⋮) → "Agregar a pantalla de inicio".
  3. Iniciá sesión con las credenciales del negocio y configurá impresoras (paso 2).
✓

Checklist antes de entregar

  • Chrome 88 instalado y abierto al menos una vez
  • BT Print Server instalado
  • Impresora conectada y test de impresión OK
  • PWA agregada a pantalla de inicio
  • Sesión iniciada con el usuario del negocio
